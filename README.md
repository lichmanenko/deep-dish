# Deep Dish

Домашний трекер питания и веса для семьи: PWA для iPhone, которая работает **полностью без интернета** и синхронизируется с домашним сервером (QNAP NAS) при появлении сети. Бюджет эксплуатации — 0 ₽.

**Статус:** v0.7.6.1 — графический канон + аудит экранов, сканер штрихкодов, справка, мост Apple Health; семейный синк на NAS, история из MFP импортирована (2017–2026). [PLAN.md](PLAN.md) · [SPEC.md](SPEC.md)

## Что это

- Дневник питания: продукты, рецепты, сохранённые приёмы пищи; ввод повторяющейся еды за 2 тапа.
- Умная норма калорий: адаптируется под фактический метаболизм (энергобаланс), а не только формулы.
- Вес и цели: тренд, прогноз, мотивационные баннеры (включая предостережения перед «окнами срывов»).
- Семья: дневники приватны, каталог продуктов общий; обмен агрегированными отчётами по подписке.
- Open Food Facts для упакованных продуктов; Apple Health через Shortcuts.
- Продуктовые метрики с первого дня, данные — только дома.

## Принципы

- **Offline-first** — сервер это невидимый слой синхронизации; приложение полноценно без него.
- **Приватность** — на сервере нет ничего идентифицирующего личность (id + псевдоним).
- **Дизайн** — воздушный интерфейс: стекло, радиальные градиенты, без рамок и явных кнопок.

## Технологии

React 18 + TypeScript + Vite + Tailwind + Dexie (IndexedDB) + Workbox (PWA). Бэкенд (M2): FastAPI + SQLite в Docker на QNAP, приватная сеть Headscale, TLS через Caddy. Деплой фронтенда — GitHub Pages (Actions).
