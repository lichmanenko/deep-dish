# Deep Dish

Домашний трекер питания и веса для семьи. Приложение устанавливается на экран «Домой» iPhone, ведёт дневник офлайн и синхронизируется с домашним QNAP при появлении связи. Бюджет эксплуатации — 0 ₽.

**Развёрнуто:** клиент v0.7.19 и сервер v0.4.9, проверено 22.11.2026. [План](PLAN.md) · [Архитектура](SPEC.md) · [Аудит](docs/AUDIT.md) · [Бэклог](docs/BACKLOG.md) · [Рефакторинг](docs/REFACTORING.md)

## Что это

- Дневник питания с локальным поиском, недавними продуктами, рецептами и сохранёнными приёмами пищи. Запись хранит КБЖУ на момент ввода.
- Норма калорий, динамика веса и цели. Адаптивная оценка включается при достаточном покрытии дневника и истории веса.
- Семейный обмен общим каталогом и достижениями через QNAP. Дневники задуманы как личные. Адресный обмен сводками и подписки относятся к 0.8.0.
- Сканер штрихкодов и внешний справочник Open Food Facts. [Мост Apple Health](docs/APPLE_HEALTH.md) читает вес через «Быстрые команды» и выдаёт итог калорий из дневника на NAS.
- Локальный экспорт JSON и CSV. JSON содержит дневник, каталог, вес, нормы и профиль. [Состав копии и восстановление](SPEC.md#10-экспорт-импорт-и-очистка)

## Принципы

- Ядро работает с локальной базой после установки. Семейный обмен и Apple Health требуют связи с NAS, внешний поиск требует интернета.
- Семейные записи, вес и профиль хранятся на устройствах и домашнем NAS. Поиск через Open Food Facts отправляет запрос или штрихкод во внешний справочник.
- Светлая и тёмная темы, пять гамм и три размера текста. [Дизайн-концепция](docs/DESIGN.md)

## Технологии

React, TypeScript, Vite, Tailwind, Dexie поверх IndexedDB и Workbox. GitHub Actions собирает клиент для GitHub Pages. FastAPI и SQLite работают в Docker на QNAP. В текущем Compose TLS обслуживает Uvicorn с локальным сертификатом. [Установка и резервирование](backend/README.md)

## Локальная разработка

Клиент собирается в CI на Node.js 22. Сервер использует Python 3.12. Для Python предварительно установите зависимости из `backend/requirements.txt`.

```sh
npm ci
npm test
npm run build
python -m unittest discover -s backend -p "test_*.py"
```
