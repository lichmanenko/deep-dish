# Факты и достижения Deep Dish — канон (v1, 25.10)

Мотивационный слой продукта: редкие факт-карточки («ты не такой, как все») и
ачивки (достижения, которые замечают). Не путать с баннерами похвалы/предупреждений
(banner.ts) — факты никогда не показываются поверх действий.

## Канон факта

1. **Две части**: число рынка + персональная рамка «а ты…». Голая статистика
   («97% бросают») без рамки демотивирует — запрещена.
2. **Простой язык**: текст понятен школьнику; без имён исследований, брендов и
   годов. Всё умное — по ссылке источника («Источник →»).
3. **Относительные величины** в персональных частях и ачивках (проценты, «каждый
   приём»), не абсолютные килограммы/даты — наружу уходят только относительные.
4. **Два независимых источника** на каждый факт (или мета-анализ PMC + независимый
   пересказ). Один источник = статус «допроврить», в приложение не идёт.
5. **Субагент-проверка перед выпуском**: формулировка однозначна, число не искажает
   источник, нет противоречий с другими фактами базы (В., 25.10).

## Механика показа

- Частота: не чаще **1 факта в 3 дня**. Баннер дня важнее — факт уезжает на завтра.
- Момент: первый вход в «Сегодня» за день.
- Приоритезация (при 2+ кандидатах, без случайности):
  1) личная веха сегодня (ачивка) → 2) возврат после пропуска → 3) стрик-веха
  (3/7/14/30) → 4) стаж-веха (30/50/100/180/365) → 5) хвост механик (не чаще
  1/9 дней). Внутри класса побеждает более редкий факт, затем давно показанный.
- **Прочитанность**: карточка открыта ≥4 с или тап «Источник →» = прочитан
  (никогда не повторится). Закрыта раньше = повтор через 5+ дней, максимум
  2 попытки, затем факт выводится из ротации.
- Выключатель: Настройки → «Факты и достижения» (скрывает факты и тосты; доска
  заработанного остаётся).
- Метрики: `fact_shown(id)`, `fact_read(id)`, `achievement_unlocked(code)`,
  `achievement_toast(code)`.

## Регламент добора фактов

- В ритуал каждого релиза 0.7.x входит 15-минутный заход: один домен, 3–5
  кандидатов, сразу поиск вторых источников, статусы в таблице ниже.
- Сигнал: пул когорты прочитан на 70% → домен в приоритете следующего захода.
- Большой заход — раз в квартал.
- Домены-кандидаты на добор: мифы о сахаре/жирах, шаги и NEAT, белок в цифрах,
  выходные и праздники, эмоциональное переедание.
