# Deep Dish — дизайн-концепция

> Канон визуального языка приложения. Обновляется при изменении стиля, не при каждой фиче.
> История решений — PLAN.md (v5–v30); здесь — как оно устроено сейчас и почему.

## Принципы

1. **Воздушность** — пространство вместо линий: разделение отступами, не рамками; карточки без обводок.
2. **Стекло и градиенты** — полупрозрачные карточки с размытием поверх радиальных градиентов (пресеты по углам, интенсивность ×1); акценты — градиент от основного тона к светлому.
3. **Кольцо — фирменный мотив** (иконка И4, кольцо калорий, кольцо цели, мини-кольца): прогресс всегда круглый.
4. **Без кнопочности** — действия выглядят как ссылки/строки, кроме главного действия экрана (одна акцентная кнопка).
5. **Сдержанные эмодзи** — максимум один на блок; в баннерах обязательны, в остальном — по необходимости.

## Компоненты

### Кольца
- **Кольцо калорий** (96px, штрих 10): остаток дня; тап переключает в сегментированный вид Б/Ж/У — три дуги оттенками одного цвета (насыщенность 1 / 0.62 / 0.36), размер не меняется.
- **Кольцо цели** (тот же размер): прогресс = тренд/план, без обрезки; ≥190% показывает «×2», ≥290% — «×N»; заполнение капается на 100%, светофор <50 warn / <80 acc / ≥80 ok. При «держать»/без цели — скрыто.
- **Мини-кольцо** в списке (46px) — точечные индикаторы.

### Панель итога («Сегодня»)
Три равные колонки: кольцо слева (центр над панелью белков), текст по центру («1 704 / из 2 060 · 83%» — без «ккал»), кольцо цели справа (центр над панелью углеводов).

### Шиты (bottom sheets)
Скругление 30px сверху, плотный фон `--panel`; закрытие — свайп вниз за шапку (ручка + заголовок, порог 70px или флик) или тап по затемнению. Кнопка ✕ не используется.

### Баннеры (top sheets)
Плашка сверху с градиентной кромкой слева (warn — тёплой); закрытие крестиком; авто-скрытие после 3 действий с едой; раз в день каждый.

### Кнопки
- `dd-action` — главное действие: градиентная заливка акцентом, текст цвета акцента; `strong` — ярче.
- Опасное действие — текст цвета `--warn` (не красная заливка), кроме явных подтверждений.
- **Sticky-сохранение**: на экранах с правками (Профиль) при несохранённых изменениях кнопка «Сохранить изменения» всплывает фиксированно над таб-баром — правка всегда завершается в поле зрения. Принять как стандарт для экранов-форм.

### Таб-бар
4 вкладки (Сегодня, Профиль, Семья, Настройки), монохромные SVG-иконки единого стиля (линия 2px, currentColor), подписи под иконкой; панель непрозрачная, автоскрытие при скролле.

### Шапка «Сегодня»
Блок ‹дата› слева (стрелки массивные, без панелей), лого с кольцом справа; «deep dish» кеглем даты.

## Правила

- **Равные кнопки** в группе — одинаковая ширина (flex: 1): приёмы в карточке ввода, режимы цели, темпы.
- **Оттенки одного цвета** вместо радуги: сегменты БЖУ, состояния.
- Радиальные градиенты — пресетом по экрану, кросс-фейд ~300мс при переходах.
- Тёмная тема: поля — плотный непрозрачный `--panel` + явный `-webkit-text-fill-color` (полупрозрачность ломает нативные контролы iOS).
- Числа — табличные цифры (`dd-num`), тысячи с пробелом, десятичная — запятая.

## Палитры

5 гамм × light/dark, токены: `bg/bg2/bg3/panel/glass/glassStrong/tx/mut/acc/acc2/accFg/veil/tr/ok/warn`.
Семантика: `ok` — позитив, `warn` — тревога/опасность, `acc` — нейтральный акцент. Светофор цели: warn <50%, acc 50–80%, ok ≥80%.
