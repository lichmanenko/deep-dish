# Пользовательские сценарии Deep Dish (v1, 09.11)

> Канон: каждый релиз тестируется по ВСЕМ сценариям настолько глубоко,
> насколько позволяет стенд (браузер+сервер). Сценарий = пошаговый путь
> пользователя с ожидаемым результатом на каждом шаге.
> При изменении фич сценарий обновляется в том же коммите.

## СЦ 1. Первый запуск (онбординг)
1. Открыть приложение → 4 шага онбординга (простые тексты, центровка)
2. Заполнить пол/возраст/рост/вес → «без цели» или заполнить цель
3. Норма посчитана и видна на «Сегодня» (кольца с числами)
4. Таб-бар: Сегодня / Профиль / Семья / Настройки

## СЦ 2. Запись еды из каталога (главный сценарий)
1. «Сегодня» → тап «＋ блюдо» на карточке «Завтрак»
2. Экран добавления → плейсхолдер «Добавить в завтрак…»
3. Ввести «твор» → каталог выдаёт «Творог 5%» (поиск с опечатками/стеммингом)
4. Тап по продукту → карточка записи: вес предзаполнен, время сейчас
5. Изменить вес → калории пересчитались вживую
6. «Сохранить» → запись в Завтраке, кольца обновились

## СЦ 3. Запись еды через единую кнопку «＋ еда»
1. «Сегодня» → тап «＋ еда» (в AlwaysOn-зоне)
2. Слот НЕ предвыбран → автоподбор по времени (±60 мин от дефолта)
3. Выбрать продукт → слот сегментом сверху → «Сохранить»
4. Запись в правильном приёме

## СЦ 4. Создание своего продукта
1. Экран добавления → поиск «запредельныйxyz» → «Ничего не нашлось» (центр, 🔍)
2. «＋ запредельныйxyz» → форма продукта
3. Ввести Б/Ж/У → калории считаются сами (подсказка 🧮)
4. Не вводить Название → «Сохранить» → подсветка «обязательные»
5. Ввести всё → «Сохранить» → продукт в каталоге
6. Записать его → запись на «Сегодня»

## СЦ 5. Создание порционного продукта (Кортадо-кейс)
1. Создать продукт с единицей «порции (шт)» → ккал на порцию
2. Записать «1 порцию» → kcal = ккал/порцию ✓
3. Записать «2 порции» → kcal × 2 ✓
4. Тап по записи → «Порций (шт): 1» (НЕ «Вес, г») ✓
5. Изменить на «0,5» → kcal = ккал/2 ✓

## СЦ 6. Рецепт
1. Экран добавления → «+ рецепт» → название
2. «＋ ингредиент» → выбрать продукты с граммовками
3. Выход готового веса → Б/Ж/У и ккал/100г посчитаны
4. Свайн строки ингредиента влево → удаление
5. «Сохранить» → рецепт в каталоге
6. Записать рецепт → вес в граммах от выхода

## СЦ 7. Сканер штрихкодов
1. Экран добавления → кнопка сканера (иконка в поисковой строке)
2. Первый запуск → запрос камеры → разрешить
3. Навести на EAN → вибро → продукт из каталога ИЛИ создание нового с EAN
4. EAN в OFF найден → Б/Ж/У подтянуты

## СЦ 8. Редактирование и удаление записи
1. Тап по записи на «Сегодня» → карточка с весом/временем/калориями
2. Изменить вес → «станет: X ккал» пересчитался
3. «Сохранить» → запись обновлена, кольца пересчитаны
4. Тап → «Удалить» → запись исчезла

## СЦ 9. Вес и кольцо прогресса
1. Профиль → «О себе» → изменить вес → «Сохранить изменения»
2. Вес в «Динамике веса» обновился → график пересчитался
3. Правое кольцо на «Сегодня» → тап → модалка «Прогресс цели»
4. Цель по темпу: кольцо = |тренд|/|план|
5. Цель по весу: кольцо = прогноз (средний темп × всего недель) / целевая разница

## СЦ 10. Баланс приёма и дня
1. Тап по названию приёма («Завтрак») → шит состава
2. Раздел «Баланс» с вердиктами («жиры больше плана…»)
3. Точки макро у блюд-виновников + легенда «основной вклад»
4. Перекус: БЕЗ раздела «Баланс» и БЕЗ «Сохранить приём пищи»
5. Тап на калораж между кольцами → шит «Баланс дня» (все приёмы)

## СЦ 11. Семейный синк
1. Семья → подключение к серверу (админ: первый, члены: по токену)
2. «Синхронизировать» → каталог общий, дневники раздельные
3. Создать продукт → у второго члена после синка в каталоге
4. Ачивки: заработанная улетает семье, лента с фильтрами по участнику
5. Админ → «Отправить каталог всем» → у ВСЕХ свежий каталог при следующем открытии

## СЦ 12. Мост Apple Health
1. Семья → «Мост Apple Health» → «Скопировать код»
2. Собрать шорткат по инструкции (или импортировать по iCloud-ссылке)
3. Запустить шорткат → вес из Здоровья уезжает в приложение
4. Автоматизация 23:30 → ежедневный обмен

## СЦ 13. Настройки
1. Гамма → выпадающий список со свотчем
2. Размер текста: обычный / крупный / очень крупный → компакт-режим
3. Тема: авто / светлая / тёмная
4. Время приёмов: «задать время | авто» для каждого
5. «Как пользоваться» → справка (5 карточек)
6. Данные: экспорт JSON/CSV, импорт JSON, wipe

## СЦ 14. Факты и достижения
1. Факт-карточка при первом входе за день (не чаще 1/3 дня)
2. Прочитал (≥4с или тап по источнику) → не повторится
3. Профиль → Мотивация → «достижения N →» → доска
4. Незаряженные серые с подсказкой; заработанные с датой
5. Тумблер «Факты и достижения» выключает показ

## СЦ 15. Офлайн
1. Без Wi-Fi → приложение работает (офлайн-first)
2. Записи сохраняются локально
3. Семья: «Витрина откроется дома» (спокойный текст)
4. При появлении сети → авто-синк в течение 5 минут

## СЦ 16. Тёмная тема
1. Все экраны читаемы, контраст достаточен
2. Кольца, чипы, кнопки — акценты видны
3. Карточки отделены (hairline)
4. AlwaysOn-зона прозрачна (blur, не заливка)
